📋 Importação Completa — uma planilha com tudo

Cole aqui uma planilha do Excel com uma linha por funcionário e quantas colunas quiser — o sistema lê o nome de cada coluna (a primeira linha) e distribui sozinho cada informação pro lugar certo: funcionário, ASO, cada NR, integração, férias, EPI (ex: "EPI - Capacete de segurança") e folha de ponto. Colunas que você não usar podem ficar em branco ou nem existir.

Backup completo

Baixa uma cópia de tudo que está no banco de dados agora (todos os funcionários, ASOs, NRs, EPIs, integrações, férias e folhas de ponto) num arquivo só, pra você guardar onde quiser — pendrive, HD externo, seu computador. Isso não some do Supabase, é só uma cópia extra pra sua segurança.
